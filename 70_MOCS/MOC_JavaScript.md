# 🟨 MOC_JavaScript

JS, Electron, Vue, npm e front-end do MeuBolso.

## Tópicos
- Electron (desktop Windows) + Vue 3 (views clássicas, `v-html`).
- `styles.css` + Bootstrap; temas `[data-theme="dark"]`.
- `window.ICON` (icons.js), `window.I18N`/`t()` (i18n pt/en/es).
- Padrões de UI: hover lift-only (P1), largura fixa i18n (P2), raised 85% (P3).
