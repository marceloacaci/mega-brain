# 🗺️ STACK — MeuBolso

- Electron (Windows) + Node.js
- Vue 3 — views clássicas (`<script>`), `v-html`, re-render apaga estilo inline
- CSS: `styles.css` próprio + `vendor/bootstrap.min.css`; temas `[data-theme="dark"]`
- Ícones: `window.ICON` (icons.js)
- i18n: `window.I18N` / `t()` — pt, en, es
- Testes: Vitest (`npm run test`, ~127)
- Build: `npm run dist:win`; run: `npm start`
- Repo: `marceloacaci/meubolso` (v2.1.0)
